## 约定标准调弦 fixture

## 实测核验（依核验的 alphaTab.core.mjs 源码）
- `Note.getStringTuning(staff,noteString)` = `staff.tuning[staff.tuning.length - noteString]`；GP5 `readNote: newNote.string = tuning.length - stringIndex`。
- **ISR stringNumber = stringCount − note.string + 1**（1=最高音弦，对齐框架 §5.3）。
  - 实测：高弦 alpha.string=6 → ISR `6-6+1=1`；低弦 alpha.string=1 → ISR `6-1+1=6`。
- `staff.tuning` **保序直达**（不按音高排序；交替调弦保物理顺序，已实测非单调 tuning 原样返回）。
- `Beat.duration` 数值（Quarter=4）；`dynamics` 数值(0..7) → 档 = value+1。
- `realValue`（ISR `midi`）**含 capo**：GP5 capo2 → 高弦 fret0=66、低弦 fret0=42（实测）。

## capo（修正先前误判）
先前曾误判“PyGuitarPro 无 capo”；经核验源码，**GP5 以 `track.offset` 写 capo**。已生成 `track.offset=2` 的
