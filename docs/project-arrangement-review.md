[MOOER 官方产品页](https://www.mooeraudio.com/product/GE200--48.html)检索摘要确认 USB 录音及 Windows ASIO4ALL 说明；[官方 GE200 下载页](https://www.mooeraudio.com/companyfile/GE200-Downloads-138.html)列出手册及 ASIO driver。2026-09-30 直接访问两页返回403，这里只采用官方检索摘要，未确认手册正文或驱动包内容。禁止套用 GE200 Pro/Plus 参数。

- T8记录 Windows build、固件、驱动版本、USB端点、通道、可协商采样率/缓冲。同一设备输入输出优先。
- 实测 USB 干声：设备音色切换后输入是否保持干声；不能可靠获取则记录受限场景，不声明通过标准干声验收。
- ASIO/WASAPI仅测实际存在的后端，不强制48k/128。不静默安装ASIO4ALL、不擅自改用户音色/路由。
- 分别记录直通/软件监听，避免双路叠加；监听往返、音高反馈、视觉误差、校准节奏残差分别测。
- 无物理回环时标为手动/跟弹估计，不冒充纯硬件延迟；未接设备可继续离线工作但不能完成硬件门。
