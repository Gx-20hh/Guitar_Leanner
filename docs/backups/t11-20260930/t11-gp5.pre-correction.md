## 实测核验（覆盖复查"用实际源码验证 Note.string/调弦/数值 Duration"）
alphaTab 类型与**真实导入**给出（与 d.ts 注释不同、以实测为准）：
- `Note.string`：数值。本 GP5 谱例中 D 弦读作 string=5、A 弦读作 string=6；第二个早期
  手写谱又呈相反方向 → **弦号方向随谱例/写入端而变，不可假设**。ISR 采用 **pass-through（不翻转）**。
- `Stave.stringTuning.tunings`：本谱例读为 `[40,45,50,55,59,64]`（index0=最低）；早期另一谱例曾读
  `[64,…,40]` → **顺序随格式而变**，ISR 采用 pass-through。
- `Beat.duration`：数值枚举（Quarter=4），ISR `duration` 存数值（初版用 `duration.key` 系错误，已改）。
- `Note.dynamics`：数值枚举(PPP=0…FFF=7)，ISR 档 = value+1（F→6、MP→4，实测一致）。
- `Note.realValue`：只读派生（getStringTuning+fret），ISR `midi` 读取之。
