## 约定标准调弦 fixture
`string1=64(高 e) … string6=40(低 E)`，即 `[64,59,55,50,45,40]`（保物理弦序，不按音高排序）。
两音皆 fret0：拍1 = 最高弦 string1（→MIDI 64）；拍2 = 最低弦 string6（→MIDI 40）。

## 实测核验（依核验的 alphaTab.core.mjs 源码，非 d.ts 注释）
- `Note.getStringTuning(staff,noteString)` = `staff.tuning[staff.tuning.length - noteString]`（源码 ~6141）。
- GP5 `readNote`：`newNote.string = tuning.length - stringIndex`（~18548）。
- 实测（常规谱例）：最高弦 → alpha.note.string=6；最低弦 → alpha.note.string=1。
- **ISR stringNumber = stringCount - note.string + 1**（1=最高音弦，对齐框架 §5.3）。
  - 最高弦 alpha 6 → ISR 6-6+1 = 1；最低弦 alpha 1 → ISR 6-1+1 = 6。实测 midi：ISR1 fret0=64，ISR6 fret0=40。
- `staff.tuning` **保序直达**（= 文件弦序 `[64,59,55,50,45,40]`），绝不按音高排序（交替调弦保物理顺序）。
- `Beat.duration` 数值枚举（Quarter=4）；`dynamics` 数值(0..7) → ISR 档 = value+1（F→6、MP→4）。
- `realValue` 含 **capo**：capo=2 时高弦(64) fret0 → 66、低弦(40) fret0 → 42（GP 回导实测）。
